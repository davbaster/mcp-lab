# Inspect the server

The MCP Inspector is a web page that connects to your server as a client. You can list its tools and call them without writing a client yourself. Run this from the project folder:

```bash
uv run mcp dev server.py
```

`mcp dev` runs your server and opens the Inspector at a local address printed in the terminal. It downloads the Inspector with `npx` the first time, so it needs Node.js and an internet connection.

<Callout type="note" title="Your Inspector may look different">

The Inspector is a separate project and changes often. The screenshots here were taken with Inspector 2.12.0. The names of the buttons may differ a little in your version.

</Callout>

## List the tools

Click Connect (the switch on the server card), then open the Tools tab. It sends a `tools/list` request. You see `add` with its description from the docstring, and fields for `a` and `b` taken from the type hints.

<Image src="images/inspector-tools.png" alt="The MCP Inspector Tools tab with the server notes connected. The tool add is selected, and it shows the description Add two numbers and two required number fields, A and B." />

## Call a tool

Enter 2 for A and 3 for B, then press Execute Tool. The Inspector sends a `tools/call` request, and the result is 5.

<Image src="images/inspector-call-add.png" alt="The Inspector's Results panel after calling add with 2 and 3. The result is 5, and the structured output is an object with result set to 5." />

If you change `server.py`, stop `mcp dev` with Ctrl+C and start it again.
