# From function to tool

The `@mcp.tool()` decorator reads your function and builds the tool description from it. You write no schema by hand. Three parts of the function matter.

- **The name.** The tool is named after the function. `def add` becomes the tool `add`.
- **The input schema.** The type hints become a JSON Schema. `a: int` and `b: int` make two required integer properties. Without type hints the SDK cannot describe the inputs, so always write them.
- **The description.** The docstring becomes the tool's description. This is the text the model reads to decide when to call the tool.
