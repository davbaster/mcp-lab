# Hosts, clients, and servers

MCP has three roles.

- **Host:** the AI application the user works in, such as a chat app or a code editor. It runs the model and decides what the user is allowed to do.
- **Client:** a component inside the host. Each client keeps one connection to one server.
- **Server:** a program that offers context and abilities to the host through MCP. It can run on the same computer or elsewhere.

The host creates one client for each server it connects to. If a host uses three servers, it runs three clients.
