# Before you start

In this course you will learn how the Model Context Protocol (MCP) works, then build an MCP server in Python. Check that you are ready.

## What you should know

- How to write a Python function, including type hints such as `def add(a: int, b: int) -> int`.
- How to install a package with `pip` or `uv`.
- How to open a terminal and run a command in it.

## What you need

- Python 3.10 or newer on your computer.
- A code editor and a terminal.

<Callout type="tip" title="New to Python?">

CS50's Introduction to Programming with Python is a good way to learn the basics. It is recommended, not required.

</Callout>

<Callout type="note" title="This site never runs your code">

The web app shows code, but it never runs it. Type the code on your own machine and run it there.

</Callout>

If you can tick every item above, go on to the next lesson.
